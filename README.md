# gcal-stopwatch

Stopwatch that connects to your Google Calendar. Built as a desktop app that connects to Google Calendar via a GCP (Google Cloud Platform) setup.

See [SETUP.md](https://github.com/nguyenshana/gcal-stopwatch/blob/main/SETUP.md) for instructions!
